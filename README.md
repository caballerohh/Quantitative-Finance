# Quantitative Finance

An applied quantitative finance project focused on derivatives pricing, stochastic simulation and structured-product design.

The work demonstrates how financial theory can be translated into Python-based models for pricing, scenario analysis and risk-return structuring.

## Analytical Scope

- Commodity futures pricing through cost-of-carry relationships
- European call-option pricing with Black–Scholes
- Geometric Brownian Motion simulation
- Monte Carlo analysis
- Capital-protected product construction
- Downside protection and participation-rate analysis
